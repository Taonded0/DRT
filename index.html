TUTORIAL / RULES

【ステップ1：ゲームの目的】

・10フェイズ以内に画面最上部の「TRY ZONE」までボールを進めてトライを奪うこと！
・10フェイズ経過、ターンオーバー（TO）、または22mラインの外へ押し出されるとゲームオーバーです。

【ステップ2：ピッチの3つのレーン構造】

ピッチは縦のエリアによって3種類5つのレーンに分かれています。
・EL（エッジレーン / 外側）：大ゲインやキックパスが狙える反面、リスクも高い勝負どころ。
・HL（ハーフレーン / 中間）：パスやランで着実にゲインを重ねる戦術の要。
・CL（セントラルレーン / 中央）：攻撃の展開力を広げる司令塔エリア。

【ステップ3：アタックチャンネルを選ぼう】

ボールの位置で変わる5つの選択肢からルートを選びます。
・Point：堅実に中央やサイドを突く基本の攻め。
・Inside：内側を突くパス。手堅い進行。
・Middle：中央をダイナミックに攻めるルート。
・Outside：外側のスペースを狙うハイゲインアタック。
・Short：ギャップを鋭く突き刺す攻撃ルート。
・Edge：最外側(EL)を限界まで攻めるルート。

【ステップ4：ダイスを振って進めよう】

「EXECUTE」ボタンでダイスを振り、進むマスが決まります。
・数字：その数だけ前進！
・マイナス：ディフェンスに押し戻される…
・CB（クリーンブレイク）：次から進むマスが2倍にブースト！
・TO：ボールを奪われ即ゲームオーバー！

【ステップ5：特殊な出目「1OP」と「1A」】

・1OP（オフロードパス）：1マス進んだ後に追加ダイスでさらなる大ゲイン！
・1A（アドバンテージ）：逆サイドへ一発トライを狙うクロスキックが発動！
